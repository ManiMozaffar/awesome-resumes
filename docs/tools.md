# AI Resume Tools

While this project focuses on teaching you how to craft the perfect resume yourself, there are also AI-powered tools that can help automate and optimize parts of the process. Below is a curated list of tools that complement the guidance provided in this project.

## ATS Optimization Tools

- [Ajusta](https://ajusta.ai) - AI-powered ATS resume optimizer. Scores your resume against job descriptions, identifies keyword gaps, and provides AI-generated rewrite suggestions. Available as a Chrome extension for LinkedIn and Indeed.
